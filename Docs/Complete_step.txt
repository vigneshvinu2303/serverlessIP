3. Prerequisites

Before starting:

* AWS account
* AWS Console access
* Basic Python knowledge
* Basic understanding of AWS S3 and Lambda
* GitHub account

The initial deployment can be performed using the AWS Management Console.

A terminal is only required when packaging the Pillow dependency manually.

Step 1 - Select AWS Region
1. Log in to the AWS Management Console.
2. Select an AWS region.

Example:
Asia Pacific (Mumbai)
ap-south-1

Use the same region for S3 and Lambda.

Step 2 - Create Input S3 Bucket
Navigate to:
AWS Console -> S3 -> Create bucket
Create a globally unique bucket name.

Example:
vignesh-image-input-2026

Recommended settings:
* Object Ownership: ACLs disabled
* Block Public Access: Enabled

Keep other settings as default.
Click Create bucket.
Purpose:
The Input S3 Bucket receives the original images.

Step 3 - Create Output S3 Bucket
Create another S3 bucket.
Example:
vignesh-image-output-2026
Recommended setting:
Block Public Access: Enabled
Click Create bucket.
Purpose:
The Output S3 Bucket stores the processed/resized images.

Why two buckets?
The input bucket triggers Lambda.
The output bucket stores the processed image.
Using two buckets helps prevent recursive Lambda invocations.

If Lambda writes the processed image back to the same bucket that triggers the Lambda function, the new object can trigger Lambda again.

Step 4: Create IAM Role

Navigate to:
AWS Console -> IAM -> Roles -> Create role

Step 8 - Understand Pillow
Pillow is a Python imaging library.
It provides functionality for:
* Opening images
* Resizing images
* Cropping images
* Rotating images
* Converting image formats
* Editing images
* Saving processed images
In this project, Pillow is used to resize uploaded images.
Example:
Original Image
1920 x 1080
     |
     v
300 x 300
Lambda does not automatically include Pillow, so Pillow must be provided as a dependency.

Step 9 - Create Pillow Lambda Layer
We will use a Lambda Layer to provide Pillow.
Create the following directory:
pillow-layer/
The python directory must be at the root of the ZIP file.

correct structure
pillow-layer.zip
python/
    PIL/
    Pillow-*.dist-info/

Step 10 - Package Pillow
A terminal is not required for the AWS architecture itself.
The terminal is used to package the Pillow dependency.
Because Pillow contains native components, the dependency should be built for an environment compatible with the Lambda runtime and architecture.

Using the AWS Lambda Python 3.12 container is one approach.
Create the directory:

mkdir pillow-layer
cd pillow-layer
mkdir python

Build the dependency:
docker run –rm 
-v “$PWD”:/var/task 
public.ecr.aws/lambda/python:3.12 
/bin/bash -c “pip install Pillow -t python/”

Verify:
ls python

Expected:
PIL
Pillow-*.dist-info

Create the ZIP file:
zip -r pillow-layer.zip python/

Step 14 - Add Image Processing Code
Replace the temporary test code with:

import boto3
from PIL import Image
import io
import urllib.parse

s3 = boto3.client(“s3”)

OUTPUT_BUCKET = “YOUR-OUTPUT-BUCKET”

def lambda_handler(event, context):
	try:
    record = event["Records"][0]
    input_bucket = record["s3"]["bucket"]["name"]
    key = urllib.parse.unquote_plus(
        record["s3"]["object"]["key"]
    )
    print(f"Input bucket: {input_bucket}")
    print(f"Input file: {key}")
    response = s3.get_object(
        Bucket=input_bucket,
        Key=key
    )
    image_data = response["Body"].read()
    image = Image.open(
        io.BytesIO(image_data)
    )
    print(f"Original size: {image.size}")
    image.thumbnail((300, 300))
    output = io.BytesIO()
    image.save(
        output,
        format=image.format
    )
    output.seek(0)
    output_key = f"resized-{key}"
    s3.put_object(
        Bucket=OUTPUT_BUCKET,
        Key=output_key,
        Body=output,
        ContentType=response.get(
            "ContentType",
            "image/jpeg"
        )
    )
    print(f"Processed image: {output_key}")
    return {
        "statusCode": 200,
        "body": "Image processed successfully"
    }

except Exception as e:
    print(f"ERROR: {str(e)}")
    raise

Replace:
YOUR-OUTPUT-BUCKET
with your actual output bucket.

Example:
OUTPUT_BUCKET = “vignesh-image-output-2026”
Click Deploy.
